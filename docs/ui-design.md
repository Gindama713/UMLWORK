# 界面设计基线 v2（【AI-辅助】）

2026-09-28：负责人认为上一版界面缺少设计品质，本轮先记录改版规则，再实施。业务规则、DTO 与服务所有权仍以 AGENTS.md 和 api-contract.md 为准。

## 视觉与信息层次

- 采用深蓝、暖白、浅柠檬绿的机场导视色系；统一线条 SVG 图标，不使用杂乱 Unicode 图形拼接导航。
- 总览首屏以停车分区和常用工作台为中心，压缩宣传横幅和重复卡片。数字、留白、边框和标题形成清晰层次；不显示虚构增长率、收入、航班或车流。
- 车位图展示后端实际楼层、区域和车位，点击查看车位详情；道路和空间布局仅为示意，不声称是建筑平面图或真实导航路径。不扩充虚假车位来填满画面。
- 寻车以车牌、楼层、区域、车位编号为主要结果；结算以车牌、账单分项、应付额、付款/释放状态为主要信息。UUID、演示时间覆盖和故障演示放入展开区域。

## 交互与实现

- 保留现有七项业务与十个 UC。运营总览提供入场、车主服务、资源管理入口；寻车可带入结算工作台。
- 入场表单与位置结果分区，车位类型直接可选；结算使用票据式账单和清晰步骤。支付失败、待释放和已出场不得采用相同成功提示。
- 图表、可用数、状态、金额来自既有真实 API。仅进行展示用分转元、比例、日期和时长格式化，不在前端计价。
- 不增加依赖；复用 Vue、Element Plus 与 CSS/SVG。新增组件只处理图标/展示，业务调用继续在 App.vue。
- 覆盖桌面与窄屏；保留键盘焦点、表单标签、状态文本和减少动效设置。
